Getting started

FileBridge copies files between your computer and a web server. Your computer is on the left, the server on the right, and at the bottom you see the Queue with everything that is being transferred.

  1. Click Site Manager at the top and then New site.
  2. Fill in the details from your hosting provider: Protocol, Host, User and Password (see Saving your sites).
  3. Click Connect. The server's folders appear on the right.
  4. Tick the files you want on one side and click Upload → or ← Download.

Just trying something once? Use Quickconnect at the top: type the host, user and password, and nothing is saved.

Saving your sites

The Site Manager keeps all your servers, in folders if you like. It works like the one in FileZilla.

  • Protocol: SFTP (via SSH, recommended) or FTP. For FTP choose Use explicit FTP over TLS if available, so your password is sent encrypted.
  • Host and Port: leave Port empty for the usual port (SFTP 22, FTP 21). Some providers use another SSH port; they tell you which.
  • Logon Type: Normal saves the password, Ask for password never saves it. For SFTP you can also use a key file or the SSH agent.
  • Your password is kept in your computer's password store (the Keychain). When macOS asks whether FileBridge may use it, type your Mac password and click Always Allow (Windows Credential Manager) (the keyring of your desktop), never in a file.
  • Background color: the file lists get this tint while you are connected, so you always see which server you are on.
  • Duplicate copies a site with its password; drag a site onto a folder to move it.
  • Coming from FileZilla? Import from FileZilla… takes over all your sites, including their folders and (when FileZilla has no master password) their passwords.

Which username?

For FTP sites FileBridge recognises the hosting panel of the server and tells you under User what the username looks like:

  • Plesk (for example Cloud86): just the account name from the panel, such as ftp1 – without @domain. If you typed ftp1@domain.com, a button Use "ftp1" fixes it.
  • DirectAdmin and cPanel: extra FTP accounts are name@domain, such as ftp@example.com; the main account is the plain username.

Testing a connection

Doesn't it connect? Click Test connection in the Site Manager. FileBridge tries the settings from the form step by step and shows where it goes wrong: server name, port, type of server, encryption and login. Nothing is saved.

  • Where it can, FileBridge offers a fix with one click, for example Switch to SFTP when you chose FTP on an SSH port, or when FTP is blocked on your network but the SSH port is open.
  • When the server refuses the login, you see its own reply (such as 530 Login incorrect), so you can tell a wrong password from a blocked account.

When FTP is blocked

Public wifi, hotels and offices often block FTP (port 21). FileBridge then says timed out and explains this. SFTP and websites usually still work.

In Site Manager → Advanced, tick connect with SFTP instead and fill in the SSH port and user from your hosting provider. When the FTP server doesn't answer, FileBridge automatically connects to the same server with SFTP, using the same password. SSH access must be switched on for your account.

Uploading and downloading

  • Tick the files and folders you want (the box in front of each line), then click Upload → or ← Download. Shift + tick selects everything in between.
  • Clicking a file name selects nothing, so you never lose a selection by accident. One click on a folder opens it; .. goes up.
  • Double-click a file to transfer just that file.
  • Drag files between the two sides, onto a folder to put them inside it. In the app window you can also drag files from the FinderExplorer onto the server list.
  • If file exists (bottom right) decides what happens with files that are already there: Skip if exists (the default, only new files go across), Overwrite if newer, Overwrite, Skip if same size or Resume.

When some files fail, the others are still transferred and the queue shows Retry for just the failed ones. Several files go at the same time (3 by default; per site under Transfer Settings).

Uploading to a public web folder such as public_html? FileBridge warns you about files that anyone could then download, such as zips, database dumps (.sql), backups and .env files. Choose Skip these files or Upload anyway.

Selecting files

  • Select type ▾ selects all files of a type, such as .jpg, and shows only those. Choose more types to add them, choose a type again to remove it. At the bottom it says Showing only … with show all.
  • Select permission ▾ selects everything with a certain permission, such as 0777.
  • Select new ▾ compares the folder with the folder open on the other side and selects what is missing or changed there. Highlight differences colours the lists: green is missing on the other side, orange is changed.
  • ⌘A selects everything, Esc clears the selection.

Working with files

  • New folder, Rename (F2), Move to… and Delete work on what you ticked. Deleting on your computer moves files to the TrashRecycle Bin; deleting on the server is permanent and asks first.
  • Right-click a file for all actions, such as View/Edit (opens a server file in your editor and uploads it again when you save), Copy path, Open in browser and Copy URL.
  • Fill in your web addresses in Site Manager → Advanced → Web addresses, for example /public_html = https://example.com, to open files on the server in your browser.
  • The ⇄ button at the top (synchronized browsing) keeps both sides in the same subfolder. The tree button shows a folder tree next to the list. The star button saves bookmarks: a local and a server folder you jump to at once.
  • Make a column wider by dragging the edge of its header; drag the bar above the queue to make it higher or lower. Double-click to reset.

Permissions

Permissions (or right-click → Permissions…) opens the same window as in FileZilla.

  • Tick Read, Write and Execute for Owner, Group and Public, or type a number such as 755 or a change such as u+x,go-w.
  • When the ticked items differ, a box shows a dash: that permission stays as it is on every item.
  • Recurse into subdirectories also changes everything inside folders, for all items, only files or only folders. Only change items that currently have limits the change to, for example, everything that is now 0777.
  • In Site Manager → Transfer Settings you can give everything you upload to a site fixed permissions, such as 0755 for folders and 0644 for files.

Compare & sync

Compare & sync compares a folder on your computer with a folder on the server, including all subfolders, by size and date.

  • Choose the folders and click Compare. The labels at the top count what it found: Only local, Only on server, Local newer, Server newer and Identical.
  • Click a label to tick all those files and show only them; click more labels to add them, or a label again to untick it.
  • Upload checked and Download checked transfer everything that is ticked right away.
  • Or choose a Direction (upload, download or both ways) and click Run sync. Mirror also deletes files that only exist on the other side; use it with care.
  • You can change the action per file in the last column before you start.

Zips: extract and deploy

Right-click a .zip: Upload & extract… on your computer, or Extract here… on the server.

  • Choose the server folder, and whether the files go directly into it or into a new folder named after the zip.
  • The Result preview shows where the files end up and warns you when something would go to an unexpected place.
  • You set the permissions for folders and files, and whether existing files are overwritten or kept.
  • Over SFTP the zip is unpacked on the server itself; over FTP it is unpacked on your computer and the files are uploaded.

Deploy

Deploy uploads a zip (a fixed file, or the newest zip in a folder such as site-update_*.zip) and unpacks it into a server folder, optionally after making a backup of that folder. Click Save to site, and the next time it's one click.

Settings

Click the gear at the top right.

  • General: the language (also with the flags at the top) and whether FileBridge looks for updates.
  • Filters: names such as .DS_Store and node_modules that are hidden and never transferred (wildcards allowed).
  • Transfers: the maximum upload and download speed.
  • View/Edit: the editor that opens files, and whether edited files are uploaded without asking.
  • User manual: this manual. It is also behind Manual at the bottom of the window.

Updates and closing

  • FileBridge looks for a new version when it starts and every few hours. You get a message once with what is new, and Update available stays at the bottom. Download the new version and replace the app; your sites and passwords are kept.
  • The power button at the top right closes FileBridge. When files are still being transferred, or edited files are not uploaded yet, it asks first.

Plugins

Under Plugins ▾ and in the right-click menu you find extra actions, such as Calculate size, Find files by name and Zip selected items. You can add your own: every Python file in the plugins folder adds actions. Plugins ▾ → Open plugins folder shows where it is, and the template there explains everything. Choose Reload plugins after a change; you don't need to restart.

Your data and safety

  • Your sites are stored on your own computer, in the folder .filebridge in your home folder; passwords are in your computer's password store. Nothing goes anywhere else.
  • FileBridge only works on your own computer: other websites and computers can't use it.
  • The first time you connect to an SFTP server, FileBridge remembers its key. If that key ever changes, it refuses to connect and warns you, because someone could be intercepting the connection.
  • The apps are signed: notarised by Apple, so macOS opens FileBridge without a warning by DataLore, so Windows shows DataLore as the publisherthe downloads come with checksums and a GPG signature.
